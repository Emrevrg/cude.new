# Support

Cude.new is an early open-source project maintained on a best-effort basis.

## Where to ask

- Use a GitHub issue and the provided templates for reproducible bugs and focused feature requests.
- Use GitHub Discussions for setup questions, design ideas, and broader community conversation.
- Use GitHub Private Vulnerability Reporting for security issues, as described in [SECURITY.md](SECURITY.md).

## What to include

Include the Cude.new version or commit, operating system, Node.js and pnpm versions, exact reproduction steps, expected behavior, actual behavior, and a minimal log with secrets removed.

## Boundaries

Maintainers cannot guarantee response times, compatibility with every model provider, recovery of user data, or support for generated third-party projects. Never post API keys, access tokens, private source code, personal data, or proprietary logs in a public issue.
