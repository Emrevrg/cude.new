# Roadmap

Cude.new's roadmap prioritizes verifiable engineering behavior over feature count. Items are plans, not promises or announced release dates.

## Now

- Keep build, typecheck, lint, and test gates reproducibly green.
- Improve contributor onboarding, issue triage, and release documentation.
- Harden command execution, secret handling, provider boundaries, and exported projects.
- Publish fixed evaluation fixtures for planning, implementation, repair, and release tasks.

## Next

- Publish a provider compatibility matrix with methodology, cost, latency, and failure modes.
- Benchmark representative local-model and desktop hardware tiers.
- Expand threat modeling and security regression coverage.
- Document self-hosting and deployment boundaries.

## Later

- Establish a predictable release cadence and public changelog.
- Add evidence-backed evaluations for repair quality, test generation, and release readiness.
- Improve multi-target verification for desktop, mobile, extensions, APIs, and hardware project packets.

Priorities may change after maintainers review reproducible bug reports, contributor feedback, and security findings.
